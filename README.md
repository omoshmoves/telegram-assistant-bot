# 🤖 All-in-One Telegram Assistant Bot

A feature-packed Telegram bot built with Python using the `python-telegram-bot` library. It includes chat message monitoring, message summaries, and a secure math expression calculator.

## 🚀 Features

* **Interactive Menu:** Control bot features using custom inline keyboards (`/start`).
* **Message Monitoring:** Toggleable chat logging that records incoming messages in real-time.
* **Chat Summaries:** Generates summaries of recent monitored messages on demand.
* **Secure Math Calculator:** Safely evaluate complex mathematical expressions via the `/math` command.

---

## 🛠️ Prerequisites & Setup

1. **Python 3.8+** installed on your machine.
2. A Telegram Bot Token from **@BotFather**.
